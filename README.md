# 🎮 Operación Extracción 

**Operación Extracción** es un videojuego 3D de disparos en primera persona desarrollado para la evaluación del curso **Computación Gráfica y Visual**.

El jugador debe atravesar una zona infestada de zombis, administrar sus municiones, recoger suministros y llegar al helicóptero de extracción para completar la misión.

## 🧟 Descripción del juego

El jugador aparece en una zona abandonada con dos armas y munición limitada. Durante el recorrido encontrará zombis que permanecen inactivos hasta detectar al jugador.

Cada zombi tiene dos puntos de resistencia y necesita recibir exactamente dos impactos para ser eliminado. Además, el jugador puede recoger cajas de abastecimiento para recuperar munición.

La misión termina cuando:

- El jugador elimina a todos los zombis y llega al helicóptero.
- Un zombi alcanza al jugador y reduce su salud a cero.

- Three.js
